This repository contains the design and simulation of a basic 4-bit Arithmetic Logic Unit (ALU) implemented using Verilog HDL. The project was developed to understand the fundamentals of digital logic design, combinational circuits, and hardware description language programming. The ALU is one of the most important components in any processor, responsible for performing arithmetic and logical operations on binary data.

The ALU designed in this project supports multiple operations including Addition, Subtraction, AND, OR, and NOT. A 3-bit select signal is used to choose the required operation. Depending on the select input, the ALU generates the corresponding output for the given 4-bit operands. The implementation demonstrates how arithmetic and logical functions can be integrated into a single digital module using Verilog.

The project was simulated using Xilinx Vivado, and a separate testbench was written to verify the functionality of each operation. Different input combinations were applied through the testbench, and waveform analysis was used to observe the outputs and confirm the correctness of the design. The project also provides a practical introduction to writing Verilog modules, using case statements, handling combinational logic, and creating testbenches for verification.

This repository mainly contains two Verilog files:

ALU.v – Main ALU design module

testbench_ALU.v – Testbench for simulation and verification


The ALU performs the following operations:

Addition

Subtraction

Bitwise AND

Bitwise OR

Bitwise NOT


This project helped in understanding important digital design concepts such as:

combinational logic circuits

binary arithmetic operations

multiplexer-based operation selection

Verilog HDL syntax

simulation and debugging using waveforms


The design can serve as a beginner-friendly project for students learning FPGA design, Verilog HDL, and computer architecture concepts. Since the ALU is a core building block of processors and embedded systems, this project also acts as a foundation for more advanced designs such as processors, pipelined architectures, and FPGA-based computing systems.

The project was created purely for educational and learning purposes and can be extended further by adding advanced features such as carry flags, overflow detection, shift operations, comparison operations, or wider data widths.
