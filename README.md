# ARITHMETIC-LOGIC-UNIT--ALU
This project implements a 4-bit ALU using Verilog HDL. The ALU performs arithmetic and logical operations such as Addition, Subtraction, AND, OR, and NOT based on select signals. The design was simulated and verified using Xilinx Vivado.
